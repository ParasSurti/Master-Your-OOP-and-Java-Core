# ☕ Master Your OOP & Java Core

*(Before Moving to Advanced Java)*

A structured, self-driven practice sheet through **11 phases** —
designed to build rock-solid **Object-Oriented Programming** and
**Core Java** fundamentals before moving on to Advanced Java, DSA,
and backend development. Solved in **Java**. Built with **consistency**.

![Java](https://img.shields.io/badge/Java-FF6B35?style=for-the-badge&logo=openjdk&logoColor=white) ![IntelliJ IDEA](https://img.shields.io/badge/IntelliJ%20IDEA-9775FA?style=for-the-badge&logo=intellij-idea&logoColor=white) ![Git](https://img.shields.io/badge/Git-F05032?style=for-the-badge&logo=git&logoColor=white) ![GitHub](https://img.shields.io/badge/GitHub-2EA44F?style=for-the-badge&logo=github&logoColor=white)

A self-driven problem-solving habit applied to Java's core OOP and
language features. Each phase is worked through in order: write the
code, run it, break it, and fix it, before checking any reference.
